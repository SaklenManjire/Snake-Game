# 🐍 Snake Game

A simple and fun Snake Game built using HTML, CSS, and JavaScript. This project recreates the classic Snake game where the player controls a snake to eat food, grow longer, and avoid collisions.

---

## 🚀 Features

* 🎮 Classic Snake gameplay
* ⌨️ Smooth keyboard controls (Arrow keys)
* 🍎 Food generation system
* 📈 Score tracking
* ⚡ Increasing difficulty as snake grows
* 💻 Simple and responsive UI

---

## 🛠️ Technologies Used

* HTML
* CSS3
* JavaScript 



## ▶️ How to Run the Game

1. Clone the repository:

   ```bash
   git clone https://github.com/SaklenManjire/Snake-Game.git
   ```

2. Open the project folder

3. Run the game:

   * Open `index.html` in your browser

---

## 🎯 How to Play

* Use **Arrow Keys** to move the snake:

  * ⬆️ Up
  * ⬇️ Down
  * ⬅️ Left
  * ➡️ Right

* Eat the food to grow longer

* Avoid:

  * Hitting the walls
  * Colliding with your own body

* Try to achieve the highest score 🚀
